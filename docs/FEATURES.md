# Funktionen und Status

| Funktion | Status |
| --- | --- |
| Registrierung, Login, Logout, Profil | Implementiert und im Browser getestet |
| Rollen STUDENT, TEACHER, ADMIN | Implementiert; Zugriff auf APIs getestet |
| Fach-/Themen-/Lektionskatalog und Klassenstufen | Implementiert |
| Single Choice, Multiple Choice, Text, Lücke, Zuordnung, Sortierung, Mathematik, Bildauswahl, interaktiver Zahlenstrahl | Implementiert; Validatoren mit Unit-Tests |
| Antwortfeedback, Versuche, einmalige Punkte, persistenter Fortschritt | Implementiert und im Browser/API getestet |
| Klassen, Beitrittscodes, Zuweisungen | Implementiert; Rollen- und API-Test |
| Admin-Verwaltung für Inhalte, Nutzer, Rollen, Einstellungen | Implementiert; Inhaltserstellung im Browser getestet |
| Visueller Aufgabeneditor | Implementiert für alle neun Typen |
| Responsive Navigation | Desktop-/Mobiltests |
| Offline-Modus, Echtzeit-Synchronisierung, Bezahlfunktionen | Nicht implementiert |

Das Projekt ist eine eigenständige Lernplattform mit den wesentlichen Abläufen. Die Referenzfunktionalität konnte nicht vollständig verifiziert werden; Gleichheit mit allen ANTON-Funktionen wird nicht behauptet. Bilderaufgaben verwenden selbst gezeichnete CSS-Formen und keine fremden Bilddateien. Die vorhandenen Beispielaufgaben sind bewusst klein; Admins können den Katalog erweitern.
