# Nutzeranleitung

1. Öffne die Startseite, wähle **Konto erstellen** und gib Name, E-Mail und ein Passwort mit mindestens zehn Zeichen ein.
2. Im Dashboard wähle **Fächer**, dann Fach, Thema und Lektion. Ein Thema ist einer Klassenstufe zugeordnet.
3. Beantworte eine Aufgabe und wähle **Antwort prüfen**. Das Feedback zeigt, ob sie richtig war. Mit **Nächste Aufgabe** geht es weiter.
4. Unter **Fortschritt** stehen bearbeitete Lektionen und Punkte. Für jede Aufgabe gibt es Punkte nur beim ersten richtigen Lösen.
5. Unter **Klassen** kannst du mit einem von der Lehrkraft erhaltenen Code beitreten. Zugewiesene Lektionen erscheinen in der Klasse.
6. **Profil** und **Einstellungen** erlauben Namen und Avatarfarbe zu ändern. **Abmelden** beendet die aktuelle Sitzung.

Bei einer ungültigen Antwort oder fehlender Verbindung zeigt die Oberfläche eine Fehlermeldung; der vorher gespeicherte Fortschritt bleibt bestehen. Die Daten liegen in der eigenen PostgreSQL-Installation, nicht bei ANTON.
